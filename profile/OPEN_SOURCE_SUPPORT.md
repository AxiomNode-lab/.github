# Open-source Support

AxiomNode-lab builds software engineering, security, and developer-infrastructure tools. This page explains the kinds of community participation and funding that can help sustain the work.

## Projects to evaluate first

- **[AxiomGuard](https://github.com/AxiomNode-lab/AxiomGuard)** — modular security building blocks for Node.js and TypeScript services. The repository documents controls for API keys, signed webhooks, browser request policies, idempotency, safer outbound requests, rate limiting, cookies, CSRF/CORS, security headers, secret-safe logging, and repository scanning.
- **[AI Skills Hub](https://github.com/AxiomNode-lab/AI-Skills-Hub)** — a package manager and catalog workflow for agent skills, with documented source provenance, license review, and file-integrity checks.

We are prioritizing these public projects for external feedback before broadening the outreach to more repositories.

## What support can fund

Funding discussions should be tied to concrete, reviewable work:

1. **Maintenance and release reliability** — compatibility checks, packaging tests, release validation, and dependency maintenance.
2. **Security quality** — regression tests, documented threat boundaries, reproducible test cases, and a clearly scoped independent security review where appropriate.
3. **Integrations and examples** — maintained examples, framework integration tests, and documentation that helps an external developer succeed without private assistance.
4. **Community health** — issue triage, contributor onboarding, documentation, and timely responses to actionable reports.

Potential support arrangements include general maintainer sponsorship, funding for a defined deliverable, technical collaboration, and eligible open-source grant programs. Scope, budget, timeline, reporting, and any recognition should be agreed in writing before work starts.

## What sponsors can expect

For an agreed scope, AxiomNode-lab can report on completed work, test or release evidence, documented limitations, and remaining risks. Public acknowledgments can be discussed as part of the agreement.

Sponsorship does not purchase favorable security findings, suppression of vulnerabilities, control over independent technical conclusions, or a guarantee that a requested feature will be accepted. Security and release decisions remain based on engineering evidence and the project's public policies.

## How to help without funding

- Try a documented workflow and report the exact environment and reproduction steps.
- Suggest a missing integration or documentation gap with a concrete use case.
- Review open issues and contribute tests or documentation through the repository's contribution process.
- Share results that can be independently reproduced; distinguish personal experiments from production use.

## Contact

For sponsorship, grants, integrations, or a technical evaluation, contact **info@axiomnode.tech** and include the project, the problem you want to address, and the type of collaboration you have in mind.

## Transparency note

This page describes support priorities; it is not a statement that AxiomNode-lab has received a grant, secured a sponsor, or has an approved payout profile. Adoption metrics, sponsor names, funding amounts, and outcome claims should only be published when they can be verified and are appropriate to disclose.
