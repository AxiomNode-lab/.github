# Support

For help with an AxiomNode Lab project, start with that repository's README and documentation, then search existing issues before opening a new one.

Use the issue tracker for reproducible bugs, focused feature requests, documentation problems, and compatibility questions that can be discussed publicly. Include the project version, operating system/runtime, minimal reproduction steps, expected behavior, actual behavior, and relevant logs with secrets removed.

Do not post credentials, access tokens, private keys, personal data, private investigation material, or other confidential information in an issue.

Security vulnerabilities should follow the repository's `SECURITY.md` or this organization's default security policy rather than the normal public support path.
